# W-wave: 야드 스케줄 → 작업 액티브 → E3 블록 이야기 계획

데이터 계층(W-1)은 **드롭인 소스로 구현 완료** — `unity/Scripts/Data/`,
`unity/Tests/EditMode/`, `docs/data/yard_schedule_demo.json`(합성, 블록 18 × 7단계,
시연일 2026-11-05, 작업지시 12건·간섭 3·허가 누락 2). 나머지는 Unity 프로젝트
연결 후 구현한다. 씬·프리팹 직접 수정 금지(Tools > YardAX 메뉴) 규칙 유지.

## W-1. 데이터 계층 (구현 완료 — 드롭인)

- 모델: Block(7단계 일정 절단→소조립→조립→선행의장→선행도장→PE→탑재,
  중량·크기·무게중심·러그·반전 여부), WorkOrder(공정·시설·블록·시간·인원/언어/신입·
  장비·허가·환경 변수·예상 위험·특이사항), EnvironmentHour, ProcessRisk,
  ConflictTruth, RequiredPermit.
- `ScheduleRepository`: 오늘 작업(GetTodayOrders), 블록 현재 단계(GetCurrentStage),
  단계 상태 완료/진행/예정(StageStatus), 시간대 환경(GetEnvironment),
  간섭(GetConflicts), 허가 누락(GetMissingPermits).
- `FacilityMapTable : ScriptableObject` — 시설 1~22 ↔ 씬 오브젝트 이름 + 작업 액티브
  카메라 프리셋.
- EditMode 테스트 4종: 11/5 E3 = "탑재"(1도크), 오늘 12건, 누락 2, 간섭 3.

## W-2. 블록 일정 바 + 오늘 작업 보드

- 간트: 블록 18 × 7단계, 오늘 세로선, 완료/진행/예정 색 구분(StageStatus 사용).
- 상단 일정 계층 브레드크럼: 선표→대일정→중일정→소일정→**블록 일정**(현재 강조)
  — `scheduleHierarchy` 데이터.
- 오늘 작업 보드: 12건 카드(공정 아이콘·블록·시간·시설·위험 배지). ConflictTruth에
  걸리거나 GetMissingPermits>0 인 카드는 경고 배지.
- 카드 클릭 또는 간트의 "진행" 칸 클릭 → W-3 작업 액티브로 이동.

## W-3. 작업 액티브 화면

- 레이아웃: 3D 공정 장면 ≈70% + 우측 AI 작업안전지침 카드 + 상단 얇은 띠
  (작업 정보·날씨·공정 단계 위치) + 하단 얇은 띠(작업 단계 진행·경고 타임라인).
- 카메라: FacilityMapTable의 시설별 프리셋으로 비행 후 고정.
- 같은 시간·인접 작업을 3D에 함께 표시, 간섭은 연결선 강조(ConflictTruth).
- 단축키: A 전체화면 토글, ←/→ 이전·다음 작업, Esc 보드 복귀.
  발표 모드(P)와 병행 시에도 3D 비중 유지.

## W-4. 공정별 3D 장면 (단순 형상 + 파티클)

`Tools > YardAX > Create Process Scene` 로 생성, 작업지시 선택 시 해당 장면 활성화.

| 공정(시설) | 장면 요소 |
|---|---|
| 절단(11) | 절단 불꽃 파티클, 마그넷 크레인 강판 이송, 이송 경로 바닥 표시 |
| 소조립(6) | 작업대 부재 맞춤·용접 불꽃, 통로 적치물 표시 |

| 선행의장(5) | 고소작업대 배관 설치, 하부 낙하물 위험 구역 |
| 선행도장(22) | 탱크 맨홀 송풍 덕트, 가스 수치·측정 후 경과, 인접 화기 불꽃 |
| 안벽의장(9) | 선박 ZONE별 작업 박스, 상하 동시작업 경고 |

## W-5. 트랜스포터 이동 위험

- `TransporterController`: 15번 PE장→주도로→1도크 웨이포인트 주행,
  속도·회전 반경은 ScriptableObject.
- 적재 E3 크기 반영, 회전 시 블록 끝단 스윙 궤적 표시.
- 진행 방향 위험 띠: 앞쪽 N초 × 속도 길이 (속도 비례).
- 시야 가림: 블록 높이·폭으로 운전석 사각 영역 계산, 사각 안 작업자 가중.
- 보행 교차: 동선이 띠에 들어오면 교차점 경고 + 도달 예상 시간.
- 환경: 강수확률·야간 → 감속 권고 (EnvironmentHour).
- 위험도 0~100 게이지 + 이유 1줄, 띠 색 초록/노랑/빨강 실시간. "시연용 규칙" 고지.
- EditMode 테스트: 속도 2배 → 띠 길이 2배, 사각 안 작업자 감지.

## W-6. 위험 예측 + AI 작업안전지침

- `RiskRuleEngine` (규칙, LLM 아님): 간섭 / 허가 누락(GetMissingPermits) /
  환경 임계값(SO 설정) / 신입 비율 / 언어 불일치 / 블록 중량·반전 여부 →
  위험 요인 목록 + 점수.
- 위험 예측 패널: 요인별 기여도 막대, 위험 유형 옆 업계 빈도
  (2025 조선업 재해자 유형별 수치 — 넘어짐294·부딪힘239·끼임221·불균형187·
  떨어짐171·맞음169, 출처 고용노동부) 표기.
- `GuidelineGenerator`: 규칙 결과를 Yard Hub 경유 LLM에 보내 카드 형식
  (한 줄 판단 / 작업 전 확인 3 / 작업 중 주의 3 / 즉시 중지 기준 2 / 근거)으로
  문장화. **LLM 실패 시 템플릿 문장 대체** (요인→문장 테이블).
- 언어 전환 ko/vi/en/ne/uz, **Confirm 버튼 + Confirm 이력 기록**.
- 시간 슬라이더 → EnvironmentHour 변경 → 점수·지침 재계산 (16시 풍속 상승 시연).

## W-7. 실물 연동 + 1인칭 연결

- 탑재 작업 액티브 LIVE 모드: 기존 Yard Hub(G-6) 실물 연동 사용.
  화면 안내: "실물 검증은 타워크레인으로 수행".
- 탑재 장면의 하부 작업자 클릭 → F-wave 1인칭 퍼포먼스로 전환
  (PerformanceSequencer 진입점 재사용).

## W-8. 시연 모드 "E3 블록 이야기"

`data/scenes/e3-story.json` 에 단계별 {카메라, 활성 장면, 우측 카드} 정의, N 키 진행:
① 블록 일정 바에서 E3 7단계 → ② 오늘 작업 보드(간섭 3·누락 2) →
③ 트랜스포터 운송(W-5) → ④ E3 탑재 작업 액티브 + AI 지침(W-3/6) →
⑤ 실물 크레인 연동(W-7) → ⑥ 하부 작업자 1인칭(F) →
⑦ 다른 공정 장면 빠른 전환(W-4) → ⑧ 마무리.
